# Nexus Gear — Gaming Accessories Store Starter

A starter React + Vite storefront with a responsive homepage, five product categories, sample INR product cards, search, category filters, and a client-side shopping cart.

## Run on Windows
1. Install the current Node.js LTS release from https://nodejs.org/.
2. Extract this ZIP file.
3. In VS Code, choose **File → Open Folder** and open `nexus-gear-store`.
4. Open **Terminal → New Terminal**.
5. Run `node -v` and `npm -v` to check Node.js and npm.
6. Run `npm install` and wait for it to finish.
7. Run `npm run dev`.
8. Open the local address Vite prints (usually http://localhost:5173).

## Important
This is a frontend starter, not a production-ready shop. Product listings and prices are sample placeholders. The cart only exists in browser memory and resets on refresh. There is no real payment, customer account, inventory, shipping, tax calculation, order processing, or admin backend. Do not accept customer payments or orders until those systems, legal requirements, security, and business details have been implemented and tested.

“Nexus Gear” is a temporary store name and can be changed.
